# AI기반 맞춤형 관광 추천 서비스 (충청남도 공주시)

고등학교 경영정보 전공 실습 프로젝트.
내 취향을 입력하면 공주시 관광지 30곳 중에서 **나에게 맞는 3~5곳짜리 여행 코스**를 추천한다.

Python + Flask + SQLite. 설치·배포 없이 노트북 한 대에서 완주한다.
클라우드·로그인·지도 API·JavaScript를 쓰지 않는다.

## 실행

```bash
pip install flask pandas
```

```bash
python scripts/init_db.py
```

```bash
python app.py
```

→ http://127.0.0.1:5000

`init_db.py`는 재실행해도 기존 데이터를 건드리지 않는다.
처음부터 다시 만들려면 `python scripts/init_db.py --reset` (남긴 평점이 사라진다).

pandas가 없어도 전 기능이 동작한다 — `preprocess.py`가 표준 `csv` 모듈로 자동 전환한다.

## 추천이 만들어지는 방식

```
최종 점수 = 0.6 × 취향 점수 + 0.4 × 또래 평점 점수
```

- **취향 점수** — 테마 6개를 순서 고정한 벡터로 바꿔 코사인 유사도 계산
- **또래 평점 점수** — 같은 연령대·동행유형 → 같은 연령대 → 전체 → 0.5 (폴백 4단계)
- **코스 조립** — 3/6/9시간 → 3/4/5곳, 같은 테마 최대 2곳, 최소 3곳 보장

자세한 계산 과정과 손계산 예제는 [동작 로직 §4](동작로직.md#4-추천-점수-계산) 참고.

## 교사용 스크립트

```bash
python scripts/verify.py           # 완성본 검증 13항목 — 수업 전날 필수
python scripts/check_prompts.py    # 대본↔완성본 정합성 12항목
python scripts/make_seed.py        # 시드 CSV 재생성 (편향 주입 포함)
python scripts/make_snapshots.py   # 단계별 완성본 폴더 자동 생성
python scripts/make_offline_kit.py # 오프라인 설치 키트 (0.6MB)
```

**진도가 뒤처진 학생은 `snapshots/stepN_done/` 폴더를 통째로 복사해 이어가면 된다.**
이 폴더들은 완성본에서 자동 생성되므로 원본을 고쳐도 어긋나지 않는다.

## 현재 상태

| 검증 | 결과 |
|---|---|
| `verify.py` — 데이터·알고리즘 | **13 / 13** |
| `check_prompts.py` — 대본 정합성 | **12 / 12** |
| 스냅샷 6폴더 단독 실행 | **6 / 6** |
| 확장과제 | **5 / 5 구현** |

확장과제(날씨·예산 상한·코스 지도·인기 코스·실제 이동시간)는 전부 **기본값이 꺼진 선택 인자**다.
아무것도 켜지 않으면 기본 과제와 완전히 동일하게 동작하며,
이는 위 `verify.py` 13항목이 회귀 테스트로 보증한다.

## 데이터 출처와 한계

관광지 30곳은 **네이버 지역검색에서 주소가 `충청남도 공주시`로 확인된 곳**만 사용했다.
좌표(`data/spots_geo.csv`)도 검색 결과의 `mapx`/`mapy` 값을 그대로 옮긴 것이다.

**비용(`cost`)은 교육용 추정치이지 실제 요금표가 아니다.**
사찰 관람료는 2023년 면제 이후 0원으로 뒀지만 주차료는 별도이고 식당 가격도 변동한다.
수업에서 이 점을 짚어야 한다.

`data/spots_raw.csv`는 **일부러 지저분하게** 만들어져 있다(32행).
중복 2건·결측 3건·테마 표기 흔들림 19건이 들어 있고, 정제하면 30행이 된다.
Step 1~2가 이 오염을 찾아 고치는 실습이므로 깨끗하게 바꾸면 안 된다.
